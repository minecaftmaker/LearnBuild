# Curriculum model

The target journey is 12–24 months for a motivated learner under 14, with optional acceleration for adults.

Each lesson uses: tiny idea → concrete example → build step → prediction → test → reflection.

Tracks interlock rather than form isolated courses. HTTP lessons feed into servers; servers feed into Linux and cloud; cloud feeds into security and reliability.

A milestone project appears roughly every 8–12 lessons. The final capstone requires architecture, implementation, deployment, monitoring and a short written explanation.
